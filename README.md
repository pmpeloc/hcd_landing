# hcd_landing

Salua's public landing page: Next.js with static export (`output: 'export'`),
Tailwind and shadcn/ui. Sections: hero, problem, how it works, security,
team and link to the demo. Deployed on Vercel.

## Setup

```sh
npm install
npm run dev
npm run build   # generates out/ for static hosting
```

Docs (Spanish): [`../docs`](../docs). Rules: [`../AGENTS.md`](../AGENTS.md).
